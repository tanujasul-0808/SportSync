# SportSync — The Playbook

A research-driven sports equipment management concept designed to make campus sports equipment easier to find, borrow, return, and maintain.

## Project Overview

SportSync addresses common problems students face when using campus sports equipment, including uncertainty about availability, damaged equipment, and a manual borrowing process.

The project focuses on creating a simpler and more transparent equipment-borrowing experience.

## User Research

The design was informed by:

- Student interviews
- Observation of the existing borrowing process
- Empathy mapping
- User journey mapping
- Card sorting
- Tree testing
- MoSCoW prioritization
- DFV (Desirability, Feasibility, Viability) evaluation

## Key Problems Identified

- Students cannot easily check equipment availability before visiting the sports block.
- Some equipment is damaged or poorly maintained.
- Borrowing depends on a manual register.
- There is no simple way to report damaged equipment.

## Core Features

The focused solution includes:

1. **Live Availability** — Check whether equipment is available before visiting.
2. **Borrow Equipment** — Record equipment borrowing through a clear process.
3. **Return Equipment** — Track equipment returns.
4. **Damage Report** — Report damaged equipment for maintenance.

## Design Direction

The information architecture groups related features into clear categories such as:

- Dashboard
- Equipment
- My Activity
- Alerts & Notifications
- Help
